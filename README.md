# Group website

This is the repo for our group website: the **Macroscopic Quantum Optics** group, Department of Applied Physics, Aalto University.

Plain HTML and CSS, with no build step. Edit a page, push to `main`, and GitHub Pages publishes it.

- How to edit, and the design rules: [AGENTS.md](AGENTS.md)
- Preview locally: run `python3 -m http.server` here and open http://localhost:8000

Related: [group page at aalto.fi](https://www.aalto.fi/en/department-of-applied-physics/macroscopic-quantum-optics-mqo), [QCLM conference](https://qclm.aalto.fi).
